Простой парсер сайта https://ooomalina.ru/catalog/zhenskij-trikotazh/ в каталоге женского трикотажа с интерфейсом, реализованным в консоле. 

Для начала работы необходимо запустить файл main.py, после чего в консоле будет представлен список разных каталогов.
При отправки соответствующего номера в консоль, данные сохраняются в файл формата .xlsx в виде таблицы со столбцами: название товара, цена, ссылка на этот товар.
Если страница по какой-то причине не была открыта, в консоль выведется соответствующая ошибка.

Требования:
- Python 3.10+
- Установленные библиотеки из requirements.txt
